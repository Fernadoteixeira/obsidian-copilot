# Configuração do Copilot Local (Modelos Locais)

Guia para configurar o Copilot para Obsidian rodando inteiramente de forma local e privada usando Ollama, LM Studio ou LocalAI.

---

## Usando com Ollama

1. Instale o Ollama em sua máquina (`ollama.com`).
2. Baixe um modelo compatível: `ollama run llama3`.
3. Nas configurações do Copilot, selecione o provedor **Ollama** e aponte para `http://localhost:11434`.
