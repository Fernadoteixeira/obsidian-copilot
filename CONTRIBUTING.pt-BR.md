# Guia de Contribuição — Copilot para Obsidian

Obrigado pelo seu interesse em contribuir para o Copilot para Obsidian!

---

## Como Contribuir

1. **Relatar Bugs**: Abra uma issue detalhada no GitHub com passos para reproduzir.
2. **Sugerir Recursos**: Envie sugestões na aba de Issues do repositório.
3. **Enviar Pull Requests**:
   - Faça um fork do repositório.
   - Crie uma branch para sua funcionalidade ou correção (`git checkout -b minha-feature`).
   - Siga o padrão de código do projeto (`npm run lint` e `npm run format`).
   - Abra um Pull Request com descrição clara das mudanças.
