# Copilot Plus e Auto-Hospedagem

O Copilot Plus oferece recursos avançados para usuários que desejam automação profunda, sistema de memória contínua ou hospedagem local completa com Miyo.

---

## Recursos do Copilot Plus

- **Modo Agente Autônomo**: Execução de ferramentas para leitura, criação e edição de notas.
- **Sistema de Memória Persistente**: Lembrete de preferências e contexto do usuário entre sessões.
- **Miyo API & Auto-Hospedagem**: Suporte para servidor local auto-hospedado com controle total dos seus dados.

---

## Configurando a Auto-Hospedagem (Miyo)

Você pode rodar o Miyo localmente via Docker ou executável para processar embeddings e modelos locais sem depender de serviços em nuvem.
