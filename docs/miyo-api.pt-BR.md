# Miyo API

O Miyo é a infraestrutura de backend auto-hospedada para o Copilot Plus, oferecendo serviços de memória, embeddings e agentes locais.

---

## Endpoints e Integração

O Miyo fornece APIs REST para gerenciamento de memória, vetorização de notas e integração segura com o plugin Copilot para Obsidian.
