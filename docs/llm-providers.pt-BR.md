# Provedores de LLM

O Copilot oferece suporte a mais de 16 provedores de modelos de linguagem (LLMs), permitindo escolher entre serviços em nuvem ou modelos 100% locais.

---

## Provedores Suportados

- **OpenRouter** (Padrão recomendável)
- **OpenAI** (GPT-4o, GPT-4o-mini, o1, o3-mini)
- **Anthropic** (Claude 3.5 Sonnet, Claude 3 Opus, Claude 3.5 Haiku)
- **Google Gemini** (Gemini 2.5 Flash, Gemini 1.5 Pro)
- **Ollama** (Modelos locais como Llama 3, Mistral, Qwen)
- **LM Studio / LocalAI**
- **Azure OpenAI**
- **AWS Bedrock**
- **Groq, Together AI, Mistral API, Cohere** e mais.

---

## Configurando a Chave de API

Vá em Configurações → Copilot → Básico → **Set Keys** e insira a chave do seu provedor.
