## Início Rápido

1. Instale o Copilot pelos Plugins Comunitários do Obsidian
2. Adicione uma chave de API em Configurações → Copilot → Basic → Set Keys
3. Abra o painel de chat com o ícone de robô na faixa esquerda
4. Comece a conversar!

Para um passo a passo completo, veja [Primeiros Passos](getting-started.pt-BR.md).
