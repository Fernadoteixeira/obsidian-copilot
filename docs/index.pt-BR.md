## Início Rápido

1. Instale o Copilot a partir dos Plugins da Comunidade do Obsidian
2. Adicione uma chave de API nas Configurações → Copilot → Básico → Chaves de API
3. Abra o painel de chat usando o ícone de robô na barra lateral esquerda (ribbon)
4. Comece a conversar!

Para um passo a passo completo, veja [Primeiros Passos](getting-started.pt-BR.md).
