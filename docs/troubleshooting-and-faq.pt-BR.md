# Solução de Problemas e FAQ

Respostas para dúvidas frequentes e soluções para erros comuns ao usar o Copilot para Obsidian.

---

## Soluções Rápidas

- **Erro 401 / Invalid API Key**: Verifique se a chave de API foi digitada corretamente nas configurações.
- **Erro de Cota Excedida / 429**: Verifique se sua conta no provedor possui saldo ou limite disponível.
- **Busca Semântica sem Resultados**: Certifique-se de ter indexado o vault em Configurações → Copilot → Indexação.
