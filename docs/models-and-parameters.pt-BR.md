# Modelos e Parâmetros

Aprenda a ajustar os parâmetros dos modelos de IA para obter os melhores resultados de escrita e análise.

---

## Parâmetros Principais

- **Temperatura**: Controla a criatividade da resposta (0.0 para respostas exatas/factuais, 0.7-1.0 para escrita criativa).
- **Max Tokens**: Limite máximo de tokens gerados na resposta.
- **Modelo de Embedding**: Modelo usado para converter notas em vetores para busca semântica.
