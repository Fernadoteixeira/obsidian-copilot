# Busca no Vault e Indexação

O Copilot suporta dois modos de busca no seu vault: busca lexical (palavras-chave) e busca semântica (conceitos).

---

## Indexação Semântica

A busca semântica converte suas notas em embeddings vetoriais, permitindo encontrar informações relacionadas mesmo usando palavras diferentes das originais.
