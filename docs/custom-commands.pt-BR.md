# Comandos Personalizados

Os Comandos Personalizados permitem criar atalhos de IA reutilizáveis para tarefas frequentes de escrita, resumo, formatação e tradução.

---

## Recursos

- **Variáveis de Modelo**: Use `{{selection}}`, `{{title}}`, `{{content}}` para injetar partes da nota no prompt.
- **Comando Rápido (Quick Command)**: Execute um comando personalizado instantaneamente no texto selecionado.
- **Pergunta Rápida (Quick Ask)**: Janela flutuante de entrada para perguntas rápidas sem abrir a barra lateral.
